# Talentier

Talentier is an AI powered teaching assistant designed to make classrooms more interactive, visual, and organized.

Instead of asking teachers to prepare large PowerPoint presentations or search for resources during class, the system listens to the lesson in real time and automatically displays relevant visual content while also generating notes, summaries, transcripts, assignments, and other classroom resources.

The goal isn't to replace teachers at all , it's to remove repetitive work and make teaching more engaging for both teachers and students.

# The Problem we are trying to solve

Modern classrooms still rely heavily on lectures, whiteboards, and static presentations.

While these methods work well, they also have some limitations:

- Creating PowerPoint presentations takes A LOT of preparation time.
- Lessons rarely go exactly as planned, making static slides difficult to follow.
- Teachers often pause lessons to search for images, diagrams, or videos.
- Students who miss class lose access to explanations and notes.
- Administrative tasks like attendance, assignments, reminders, and quizzes consume valuable teaching time.

We aim to solve these problems by acting as a live AI assistant throughout the lesson.

---

# How It Works

The platform listens to the teacher's lecture in real time.

As the teacher explains a topic, the AI continuously:

- Understands the current concept being taught.
- Determines the teaching intent.
- Finds the best visual explanation.
- Displays images, diagrams, simulations, GIFs, textbook references, or presentations.
- Generates classroom resources automatically.

Everything happens in the background without interrupting the lesson.

# Core Features

## Live Visual Teaching

While the teacher explains a concept, the system automatically displays:

- Images
- Diagrams
- GIFs
- Simulations
- Textbook references
- Presentations

The teacher continues teaching naturally while the visuals update automatically.

---

## AI Teaching Intent Engine

Instead of matching keywords, the system tries to understand what the teacher is actually trying to explain.

For example:

Teacher:
> "Furniture is purchased using cash."

Instead of simply searching "Furniture Purchase", the AI understands that the lesson is explaining an exchange of assets and searches for visuals that make that concept easier to understand.

---

## Classroom Notes

Every class automatically generates:

- Transcript
- Summary
- Important points
- Homework
- To-do list
- Revision notes

Students can revisit the lesson anytime.

---

## Student Dashboard

Students can later access:

- Class summaries
- Full transcripts
- Homework
- Assignments
- Revision notes
- Custom practice
- Previous Year Questions
- Relevant textbook sections

Everything from one dashboard.

---

## Teacher Dashboard

Teachers can manage:

- Attendance
- Assignments
- Quizzes
- Class reminders
- Student progress
- Teaching resources

without switching between multiple platforms.

---

## Smart Attendance

Using face recognition, the system can automatically record attendance and maintain classroom records.

---

## Classroom Analytics

The platform can estimate classroom engagement using computer vision.

Examples include:

- Attention
- Participation
- Speaking activity

These insights are designed to help teachers understand classroom trends rather than evaluate individual students.

# Visual Pedagogy Engine

One of the biggest ideas behind the project is that the AI shouldn't simply search for images.
We allow our engine to choose between:

- Photographs
- Illustrations
- Diagrams
- Comparisons
- Infographics
- Simulations
- Whiteboard sketches
- GIFs

depending on the lesson.
